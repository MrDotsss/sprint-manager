# SSaaS - Simulate Support as a Service

SSaaS is a server-authoritative software development support simulation app where you manage a small team of Developers and QA Engineers to ship software releases.

It exists as a portfolio project exploring backend systems, and AI-generated content can work together in a full-stack application. The goal is to balance workload, team capacity, cost, and risk to successfully ship each sprint.

## How to Use

1. Start a new project and choose a project type.
2. Hire Developers and QA Engineers.
3. Select and assign tasks based on your team's strengths.
4. Set task priorities and start a sprint.
5. Review the development and QA results.
6. Sign off the release and use the resulting score and revenue to continue.

The server is authoritative over all game state and simulation results.
